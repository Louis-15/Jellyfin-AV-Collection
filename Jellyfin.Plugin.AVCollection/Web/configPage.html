基本设置

按演员把影片归进 Jellyfin 合集，用演员头像做合集封面， 并可以把同一位演员的多个艺名合并到一个合集里。 计划任务每 6 小时跑一次，也可以在本页手动触发。

关闭后计划任务不再改动任何合集。

合集规则
按作品数从多到少取。设为 2 时，「小野夕子」和「葵」合并后合集名是「小野夕子 / 葵」。
把「葵」「小野夕子」并进「小野夕子 / 葵」之后，删掉前两个只剩单部影片的空壳合集。 不勾选则保留，由你自己清理。
合并组使用「封面艺名」那一张头像；未指定时用作品数最多的艺名。
Jellyfin 偶尔会把演员合集匹配成同名电影（例如「かすみ」→《真田女忍者霞传》）， 勾选后会清掉错误的简介、首播日期和背景图。
媒体库扫描期间演员信息可能为空。扫到的演员少于这个数量时直接中止，避免把合集清空。
艺名合并

把「其实是同一个人、但用了不同艺名」的演员勾在一起，点「合并选中的艺名」。 合并后他们共用同一个合集，影片也会并到一起。

AI 设置（可选）

「AI 智能合并」用的模型配置。模型只给建议，必须你点「采纳」才会生效。

关闭后「AI 智能合并」按钮会直接提示未启用。
Open Code 已内置 https://opencode.ai/inference/go/openai/v1， 并自动附带它要求的 x-opencode-session 请求头。
不含 /chat/completions，例如 https://api.deepseek.com/v1。
只保存在服务器插件配置里，不会写进日志。
Open Code 可用：deepseek-v4.1-flash、glm-5.3-flash、kimi-k3 等。
推理模型判断几十位演员通常要 2-3 分钟，默认 300 秒。 改小会让「AI 智能合并」更容易超时。
建议先点「测试连接」确认 Key 和地址没问题，再去上面的「艺名合并」点「AI 智能合并」。
